# Lubi v1.5.1 数据可靠性加固

日期：2026-10-02

> 历史实施记录：这些改动已合并到 v1.6.0，当前版本和验证边界以根目录 CHANGELOG 为准。

## 本次修改

- `src/core/time.ts`：日期校验改为严格日历校验，拒绝 `2026-02-31`、`2026-13-01` 等会被 JavaScript 自动进位的日期。
- `src/core/journal.ts`：`readRange()` 保持调用方日期顺序，避免并发读取完成顺序影响“最近记录”和“接着记”；编辑跨午夜记录时也校验次日 24 小时上限。
- `src/core/tasks.ts`：任务 JSON 损坏时自动备份原文件、显示错误并进入只读保护，避免静默清空后覆盖用户数据；修复一次写入失败后队列永久拒绝的问题。
- `src/main.ts`：Vault 变更事件增加 120ms 防抖；内部写入只刷新视图，不重复扫描最近 14 天日记，也不重新加载自己的任务快照，避免拖拽和连续编辑时的重复渲染与状态回退。
- `test/run.mjs`：增加严格日历日期回归测试。
- `test/stub-obsidian.js`：为核心测试补齐 `Notice` 模拟导出。

## 验证

- `npm run build`：通过。
- `npm test`：通过。
- 当前源码构建产物与 `.obsidian/plugins/lubi/` 安装版仍需在发布时重新同步并核对哈希。
