# 历史名称候选（需求已确认）

## 已确认
- 用于规划任务与记录时间，二者共用候选；记录支出暂不涉及。
- 候选来自当前分类的历史时间记录名称与已有任务名称，去重展示。
- 选择候选只填入名称，不关联旧任务，也不带入日期、时长或完成状态；允许自由输入新名称。
- 空输入时按最近使用时间倒序展示；最多露出 5 行，其余在列表内滚动查看。
- 输入后实时筛选，结果同样最多露出 5 行，其余滚动查看。
- 新任务或记录成功保存才算使用；点击候选或取消表单不算。既有历史记录按记录日期、任务按创建时间作为初始依据，不按计划执行日期排序。
- 不自动合并历史名称，不修改历史统计。
- 搜索采用文字包含匹配，英文忽略大小写，忽略查询首尾空格；不做拼音、错别字或同义词匹配。
- 切换分类保留已输入名称，只切换候选范围并按当前输入重新筛选；不自动清空或替换名称。
- 最近使用顺序在关闭或重启后保留；补记旧日期的记录按本次成功保存时间更新最近使用。额外在本地保存名称使用时间，不改任务 schema 或日记格式，不上传网络。
- 编辑已有任务或时间记录也支持候选，点击名称输入框展开，不自动改变原名称；主动选择才替换文字。只修改日期、时长或备注不更新名称最近使用时间。
- 无候选或无匹配时收起列表，保留自由输入，不增加提示或弹窗。
