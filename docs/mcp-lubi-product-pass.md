# Lubi 产品体验优化第一轮

日期：2026-10-02

> 历史实施记录：已并入 v1.6.0；当前功能说明以 README 和教学手册为准。

## 已落地

- 每日页增加“今日摘要”带：记录投入、实际覆盖、并行重叠、待确认记录。
- 每日摘要在存在任务时增加“计划完成”进度，直接连接计划与实际。
- 回顾页增加“本期时间结构”带：记录投入、实际覆盖、并行重叠。
- 回顾页增加“最多投入”分类洞察，帮助快速定位时间主要去向。
- 由每日记录自动生成的任务显示“由记录生成”来源标签，解释双向同步。
- 摘要指标提供 tooltip，解释记录时长与实际覆盖的区别，避免把并行重复计时误认为真实投入。
- 摘要在窄栏下支持横向滚动，不压缩主要内容，也不引入新的弹窗路径。
- 重复任务支持“跳过本次”：只写入单日 `skipDates` 例外，不改变原重复规则，并用成功/失败 Notice 解释结果。
- 任务数据归一化兼容旧数据；Vault 刷新区分内部写入与外部修改，降低拖拽、编辑时被旧事件覆盖的风险。
- 增加“导出全部记录 CSV”命令，并放入面板更多菜单；字段含日期、时间、时长、分类、标题、任务、金额、支出类型和备注，文本按 CSV 规则转义并带 UTF-8 BOM。

## 产品原则

- 先给结论，再展示细节。
- 颜色继续表达分类，状态用边框、纹理和徽标表达，避免颜色语义过载。
- 统计同时展示“记录投入”和“实际覆盖”，保留柳比歇夫记录法的可解释性。
- 新增数据字段时保持旧数据可读、默认值明确，并让异常操作可解释、可恢复。
