# Lubi v1.5.0 优化记录

> 日期：2026-09-27 ｜ 基线：`9a82a56`（v1.4.1 后续改动快照）｜ 依据：v1.4.1 评审结论

## 改动

| # | 问题 | 改动 | 文件 |
|---|---|---|---|
| 1 | 每日页看不到计划，计划与实际要切页对照 | 时间轴右侧新增虚线「计划」列：当天有开始时间、未完成且还没有关联记录的任务；点击预填一条关联记录，保存后任务自动完成；过了计划时间标橙 | `插件源码/lubi/src/ui/today.ts` |
| 2 | 勾选完成按计划时间自动记录，估计值混进实际统计 | 自动记录写入 `[待确认:: 按计划]`；时间轴虚线 + 「待确认」徽标；拖动调整、表单保存或点 ✓ 后去掉；回顾页主 KPI 提示待确认时长 | `插件源码/lubi/src/core/records.ts`、`插件源码/lubi/src/ui/taskList.ts`、`插件源码/lubi/src/ui/review.ts` |
| 3 | 每日页右栏只有一张卡，下方大片空白 | 右栏新增「今日计划」（完成度 + 没定时间的计划，可直接记录或按预计完成）与「空白时段」（最长 4 段，定位 / 补记） | `插件源码/lubi/src/ui/today.ts` |
| 4 | 两页时间刻度不一致（56 / 44 px/h） | 共用 `HOUR_PX = 48` | `插件源码/lubi/src/ui/components.ts`、`插件源码/lubi/src/ui/today.ts`、`插件源码/lubi/src/ui/tasks.ts` |
| 5 | 新建窗口「已完成 / 支出 / 待做」混了状态与类型 | 一级「记录 / 任务」，二级「时间 / 支出」，两者同一行 | `插件源码/lubi/src/ui/modals.ts` |
| 6 | 任务状态改动有两处反馈 | 删除「已选择…保存后生效」，只保留标题旁「● 未保存」 | `插件源码/lubi/src/ui/modals.ts` |
| 7 | 顶栏主按钮「新建」含义模糊 | 每日 / 回顾页显示「记一条」，任务页显示「加任务」 | `插件源码/lubi/src/ui/view.ts` |
| 8 | 预览生成依赖运行时刻，深夜运行时布局用例失败 | 演示数据至少生成到 14:00；取块 / 任务行时有兜底 | `插件源码/lubi/test/preview.mjs` |
