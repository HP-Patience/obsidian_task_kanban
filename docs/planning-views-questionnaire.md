# 计划页三种展示方式：实现约定

状态：已实现。构建、核心、实际压缩生产包完整冒烟及必需浏览器布局检查已通过；真实 Obsidian / 物理移动端操作尚未验收。未创建新 Release 或标签。

## 已确认的目标

计划页提供日历、甘特图、列表三种展示方式；每一种都支持日、周、月时间范围。

## 已确认规则

| # | 规则主题 | 已确认答案 |
| --- | --- | --- |
| 1 | 日历具体如何展示？ | 日、周用 0–24 点的纵向时间轴；月用标准月历格子，不把整月画成密集的小时列。 |
| 2 | 日、周、月的范围如何定义？ | 日为选中日；周统一周一至周日；月为自然月。月历首尾补齐周格，邻月日期弱化；甘特和列表只统计当前自然月。现有周日程围绕选中日的滚动七天改为自然周。 |
| 3 | 默认打开哪种方式，是否记忆选择？ | 首次打开为日历·日，日期选今天；本次打开期间记住展示方式、范围与日期，重启不新增持久化设置。 |
| 4 | 两组切换和日期导航是否共用？ | 三种展示方式共用日/周/月、选中日期、上一段/下一段/今天；切换方式不重置日期或范围，顶栏与计划共用日期，回顾周期导航保持不变。 |
| 5 | 什么任务应出现在范围内？ | 三种方式采用同一套规划任务范围规则：安排日期落入范围，或显式跨度与范围相交；重复任务按范围内的发生日展示。无日期任务放未安排，不混入实际记录或支出。 |
| 6 | 原有侧栏如何处理，避免列表重复？ | 各展示方式和周期的原有侧栏统一放在右侧，宽度与日历·日一致为 300px；面板宽度不超过 900px 时统一放在主内容下方并自适应宽度；日历、甘特保留选中日任务与未安排入口；日历·日整合原每日页，左侧实际 / 计划 / 支出时间轴，右侧分类分布、计划进度、未安排和空白时段，任务清单默认展开、按开始时间排序；列表直接承载范围任务，不再重复放一份当天清单，仍保留未安排区域及排期入口。 |
| 7 | 列表如何排序与组织？ | 日列表按开始时间，未填时间放后；周/月按日期分组、组内同样排序，同时间按现有顺序。普通跨日任务只列一次并显示跨度；重复任务按发生日列行；保留父子关系，不新增另一套排序数据。 |
| 8 | 任务条和列表行默认显示什么？ | 默认只显示任务名、计划时间/跨度、分类色及完成状态；预计与实际用时等详情沿用现有悬停与编辑位置，避免每行堆满说明。日/周/月任务名称都左对齐。 |
| 9 | 不同方式支持哪些拖动？ | 日/周日历与日甘特按时间移动、拉伸；月历拖到其他日期，跨度通过现有表单修改，不新加月历拉伸；周/月甘特保留按日期移动和拉伸；列表保留现有排期入口，不新做拖动时长。拖动只改计划，不改实际记录。 |
| 10 | 完成、重复和父任务如何保持一致？ | 已完成任务仍显示，名称划线、颜色弱化，不增加标题前的完成勾。重复任务完成只作用于指定发生日；重复与父任务汇总的拖动限制沿用现有规则，不用拖动暗改整组子任务。 |
| 11 | 点击、空白选区和新建怎么工作？ | 点击任务进入现有编辑表单；周日历空白选区默认规划任务；日历·日保持记录 / 计划分区创建，并带入日期、开始和时长；月历选中日期后用现有新建入口，列表新建带入选中日期。只保留一个明显的主新建按钮，不新增弹窗，也不顺带改 AI 入口。 |
| 12 | 空数据、窄屏及此次改动的边界？ | 无任务仍保留日历格子、甘特坐标和列表日期标题，给简短空提示。窄屏切换仍可用，必要时仅图表区域滚动，不取消任一种展示。合并原每日页至计划日历·日并删除独立入口，不改回顾布局、任务 schema v14，不改实际用时保存逻辑，不加年范围或新装饰效果。 |

## 关键验收场景

- 日历·周切到甘特或列表，保持同一自然周及选中日期。
- 单日任务在三种方式均可定位；跨日任务相交可见，列表不按每天重复列同一个普通任务。
- 重复任务展示范围内各发生日，完成其中一天不完成其他天。
- 月末切到下月不因目标月份天数较少而越过目标月份。
- 排期拖动不修改日记实际记录；查看与切换不写入任务数据。
- 未安排、已完成、空数据及窄屏均有可用入口与稳定布局。

## 实现边界

- 有自身明确排期的父任务保留；仅从子任务推导的父级范围作分组或甘特汇总，不伪造成日历时间分配。
- 月历跨日任务从所拖动的发生日期计算平移量，原位落下不写入；拖到邻月日期后定位目标月份，避免排期成功却看不到任务。
- 已完成的范围内任务仍显示；未安排区域沿用已有的未完成任务规则。
- 日历固定全天，因此移除不再生效的旧日程时段控件；兼容设置字段仍保留，不迁移或重建个人数据。
- 浏览器覆盖三种展示 × 三种范围，明暗主题及 1400 / 800 / 390 / 320px；模拟交互覆盖日期导航、跨日 / 重复任务、父任务、取消及实际记录不被排期修改。静态预览和模拟 Vault 不等于真实 Obsidian 或物理移动端验收。
