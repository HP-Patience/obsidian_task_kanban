# Lubi 插件 · 使用说明与构建

> 当前版本 **v1.4.0**。源码在 `插件源码/lubi/`，已安装到 `.obsidian/plugins/lubi/` 并加入 `community-plugins.json`。
> 一句话：柳比歇夫时间统计法 —— 记一条、看一眼、排一下，三页搞定。
> 面向使用者的完整教程见保险库根目录 [[Lubi 教学手册]]；v1.4 界面改版的设计依据见 `docs/mcp-lubi-ui-optimization-plan.md`，下方「v1.4 新增速览」是用法摘要。

### v1.4 新增速览

- **顶栏**：左 = 日期 / 当前周期，中 = 三个页签（切页时位置固定不跳），右 = 「记一条」+ `⋯` 菜单（打开日记文件 / 快捷键 / 设置）。今天的日期旁有「今天」徽标。
- **快捷键**（焦点在 Lubi 面板内时生效，`?` 查看）：`N` 记一条，`1` `2` `3` 切页，`T` 回到今天，`←` `→` 前一天 / 后一天；记一条弹窗里 `Alt+1…9` 选分类。
- **一行快速记录**：在「做了什么」里直接写 `9:00-10:30 学习 三明治定理`、`学习 45min 背单词` 等，下方会提示「识别为 …」，时间、时长、分类自动填好。
- **补记空白**：时间轴上超过 30 分钟的空白，鼠标移上去出现「记这段 · 起–止 · 时长」，点一下就按这段时间新建。「接着记」从上一条结束时间开始。
- **时间轴**：睡眠等「背景时间」用斜纹降权；并行记录右上角有角标，重叠说明收进标题栏徽标；视口外还有记录时出现「↑ / ↓ 还有 N 条」浮标；区块 ≥ 40px 才显示第二行（时间 · 备注）。
- **今日收尾**：21:00 后记录页右侧出现收尾卡（覆盖率、最大空白、明天第一件事），可在设置关闭。
- **待办 ▶**：今日待办行悬停出现 ▶，点一下按「接着上一条到现在」预填记录。
- **回顾页**：总时长大卡 + 环比（两期都有足够有效天数且无异常日才显示）；异常日提示压成一行并可直接「校对」；堆叠柱里睡眠固定在最底层；年视图新增全年覆盖热力图（点某天跳到该日）；Top 10 带比例条。
- **任务页**：周日程每天表头有负载条（计划时长 ÷ 每日可用小时，≥90% 橙、超过红）；项目区折叠时也显示各项目名 + 进度条；全天任务完成后带 ✓；预计时长可写 `1.5h`、`90min`、`1h30m`。
- **配色**：分类色与主题强调色拉开色相（≥ 30°），升级时只替换你没改过的默认色；设置页若发现分类色与强调色太像会给出提示。

## 1. 开始使用

**重载 Obsidian**：`Ctrl+P` → 输入「Reload app without saving」回车（或直接重启）。左侧 ribbon 会出现沙漏图标 ⌛，点击即打开面板。若开启了「受限模式 / Restricted mode」，需先关闭。

命令面板（可绑快捷键）：`Lubi: 记一条`、`Lubi: 打开面板`、`打开面板 · 记录页 / 回顾页 / 任务页`、`打开今天的日记文件`、`迁移旧数据`。

---

## 2. 三个页面

顶栏三段式：左 `‹ 日期 ›` / 当前周期 ｜ 中 **记录 · 回顾 · 任务**（位置固定）｜ 右 `＋ 记一条` 与 `⋯` 菜单（打开日记文件 / 快捷键 / 设置）。

### 记录（默认页）

- **24 小时时间轴**：每条记录按开始时间落位，高度 = 时长，颜色 = 分类。留白的地方就是「时间黑洞」。块最宽 960px（CSS 变量 `--lubi-tl-max`），右侧财务栏只在当天有财务记录时出现。
- **拖动**：
  - 按住块身上下拖 → 移动（时长不变）；拖块的上 / 下边缘 → 改开始 / 结束；
  - 在空白处按下往下拖出一段 → 松手弹出「记一条」，时间已填好；
  - 吸附 5 分钟，按住 `Shift` 为 1 分钟，按住 `Alt` 吸附到相邻记录的边缘；拖动中块内和左侧刻度实时显示时间；
  - `Esc` 或右键取消；松手后右下角 Notice 有 6 秒「撤销」；不能拖出 00:00–24:00。
- **键盘**：点过一个块后 `↑/↓` 移动 5 分钟（`Alt` 为 1 分钟），`Shift+↑/↓` 改时长，`Enter` 编辑，`Delete` 删除，`Esc` 取消选中。
- 双击时间轴空白处：在那个时刻记一条。
- 悬停一条记录：编辑 / 复制到明天 / 删除。点击（不拖动）直接编辑。
- 右侧：今日分布环形图、覆盖率、支出、**今日待办**（勾掉一个任务会顺手让你记下实际用时，可在设置关闭）。
- 第一次打开会显示「三步上手」卡片，右上角 × 可永久关闭。
- 历史日期与统计口径已校正：重叠时段、跨天记录与异常时长都会给出口径说明，不会默默算错。

### 回顾

- 周 / 月 / 年三档，`‹ ›` 切换，「本期」回到当前。
- KPI：总时长、有记录天数、日均、覆盖率（记录时长 ÷ 24h）、支出。
- 每日堆叠柱：纵轴 24h 封顶（年视图按最大月自动取整），6/12/18/24h 虚线网格，虚线为本期日均；某天超过 24h 会截断并标 ⚠（数据有误，去那天修）。悬停显示各分类小时数；点某一天跳到那天的记录页；年视图点某月进入该月。
- 按分类明细、事项 Top 10、支出按类别 + 最近 30 笔。

### 任务

- 左上 **今天**：当天任务清单；底部输入框回车即添加。勾选 = 完成。
- 左下 **未安排**：没有日期的任务，`日历+` 按钮安排到当天，或直接**拖到右侧日程**。
- 右侧 **本周日程**：7 列 × 小时。任务块可上下拖改时间、左右拖换天、拉下边缘改预计时长（15 分钟吸附，`Esc` 取消）；左侧清单拖到表头改为全天；双击空白新建；点击编辑。
- 底部 **项目**：有子任务的顶层任务自动成为项目，显示进度 `完成/总数` 和时间跨度条（极简甘特）。跨度 = 项目自身的开始/截止，或由子任务日期推导。**条形可拖**：整条左右拖 = 移动（项目改 startDate/endDate，叶子任务改安排日期）；拉两端 = 改跨度；拖动中条上实时显示 `起 → 止 · N 天`。
- 完整父级路径、长标题与元信息在窄栏内换行显示，不溢出卡片；左栏宽度按面板在 300–360px 间自适应。

### 记一条（模态）

标题带日期与原时间段；顶部 3px 色条 = 当前分类。分类胶囊 → 做了什么 → `开始 ── 时长 ── 结束` 联动条（时长胶囊点单位可切 min / h）→ 快捷时长 15/30/45/60/90/120（当前值高亮）→ 「从 xx:xx 接着记」（上一条的结束时间）。
`+ 关联待办` `+ 备注` 点开才出现，右上角 × 收起并清空。财务类改为 时间 + 金额 + 类别。左下「删除」为文字按钮。回车保存；校验不通过会明确报错并留在原地。
跨过午夜自动拆成两天；单日总时长超过 24h 会拒绝并提示剩余可记分钟数。

## 3. 数据格式（人可读、可手写）

**日记** `日记/YYYY-MM-DD.md`，插件只管 `## 记录` 这一节，其他内容随便写：

```markdown
---
date: 2026-09-24
---

# 2026-09-24

## 记录
- 01:10–07:25 学习 · 三明治定理习题 [时长:: 6.25h] [任务:: 427a21a1-…]
- 12:30 财务 · 午饭 [金额:: 35] [类别:: 餐饮]
- 20:00–20:45 学习 · 写测试 [时长:: 45min] [备注:: 顺利]

## 随笔
今天状态不错。
```

行格式：`- 开始[–结束] 分类 · 标题 [字段:: 值]…`。时长可写 `1.5h` / `90min`；没有 `时长` 字段时按起止时间算。手写一行保存后面板会自动刷新。Dataview 可直接查询这些内联字段。

**任务** `任务/任务数据.json` v14，一张扁平表，12 个业务字段：
`id title category parent status(todo|doing|done) blocked date start estimate repeat{kind,days} doneDates startDate endDate notes order`。

> 2026-09-26 已初始化：`日记/` 与任务数据清空、插件设置恢复默认（见 `docs/mcp-lubi-cleanup.md` 第六节）。

## 4. 设置页

日记文件夹、任务数据文件、备份文件夹、日程显示时段（默认 6–24 点）、勾任务时是否弹记录框、每日可用小时（任务页负载条，默认 8）、晚间「今日收尾」卡片开关、分类（名称 / lucide 图标 / 颜色 / 时间或金钱 / 是否「背景时间」）、支出类别、迁移旧数据、重新显示引导。

## 5. 源码与构建

```
插件源码/lubi/
├─ src/main.ts            插件入口：命令、事件、迁移提示
├─ src/settings.ts        设置与默认分类
├─ src/core/records.ts    记录行解析 / 序列化
├─ src/core/journal.ts    日记读写（只动 ## 记录 节）
├─ src/core/tasks.ts      任务模型 v14、查询
├─ src/core/metrics.ts    统计口径：重叠时段、覆盖率、异常时长
├─ src/core/migrate.ts    日记格式迁移
├─ src/core/time.ts       日期时间工具
├─ src/core/color.ts      颜色解析、色相差、分类色与强调色撞色检测、默认色迁移
├─ src/core/quickparse.ts 一行快速记录与预计时长的自然语言解析
├─ src/ui/view.ts         主视图（顶栏 + 三页路由）
├─ src/ui/today.ts        记录页
├─ src/ui/review.ts       回顾页
├─ src/ui/tasks.ts        任务页
├─ src/ui/drag.ts         拖动与键盘交互
├─ src/ui/modals.ts       记一条 / 任务 / 确认 模态
├─ src/ui/settingsTab.ts  设置页
├─ src/ui/components.ts   按钮 / 分段控件 / 环形图等
├─ styles.css             全部样式（token 在 .lubi-root 上）
├─ scripts/               命令行迁移脚本（可 --dry）
└─ test/                  核心单测、jsdom 冒烟、浏览器布局回归
```

改代码后：`cd 插件源码/lubi && npm install && npm run build`，再把 `main.js` `styles.css` `manifest.json` 复制到 `.obsidian/plugins/lubi/`，重载 Obsidian。
（`LUBI_OUT=../../.obsidian/plugins/lubi npm run build` 可直接输出到插件目录。）

测试：`npm test`（核心 + 冒烟 + 布局回归）；布局用例需要 headless Chrome，用 `LUBI_REQUIRE_BROWSER=1` 强制启用。`test/topbar-layout.mjs` 用真实视图在 1400 / 1000 / 720 宽、明暗两套主题下检查：页签横向位置跨页一致、可见文字 ≥ 11px、文字对比度 ≥ 4.5:1、时间轴首个小时标签不被裁切、顶栏不溢出。

预览截图：`node test/preview.mjs && python3 test/shot.py`，输出到 `preview/`（浅色 1400 宽）、`preview/dark/`、`preview/narrow/`（720 宽）。

当前安装版与源码一致：`styles.css`、`manifest.json` 逐字节相同（SHA-256 `029f80557e118ec9…`、`24adb69e8267b4fe…`）；`main.js` 为 esbuild 打包产物。
