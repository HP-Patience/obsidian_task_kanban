## 1. 设计原则（全程判断依据）

1. **数据是主角，界面退后**（参考 Linear / Things 3）：彩色只留给分类数据；界面控件一律中性色，唯一强调色只给主 CTA 与当前态。
2. **一眼回答一个问题**：记录页回答"今天去哪了"；回顾页回答"这段时间的趋势与异常"；任务页回答"接下来做什么、排得下吗"。
3. **稳定的空间记忆**：顶栏、侧栏、卡片位置在三页间不跳动。
4. **键盘优先，鼠标同等**：每个高频动作都有快捷键且在界面上可发现（参考 Linear 的 kbd 提示）。
5. **跟随 Obsidian 主题**：所有颜色走 token，明暗主题、第三方主题都能自洽。

## 3. 设计系统（Design Tokens）改造

现状：`styles.css` 只定义了 gap / radius / 少量颜色 token，大量硬编码（卡片 `12px` 圆角、按钮 `32px` 高、标题 `14px`、`rgba(0,0,0,.08)` 阴影）。

### 3.1 新增 token（全部挂在 `.lubi-root, .lubi-modal` 上）

```css
/* 语义色：界面用，不给数据用 */
--lubi-accent: var(--interactive-accent);
--lubi-info:   var(--color-blue);
--lubi-warn:   var(--color-orange);
--lubi-danger: var(--text-error);
--lubi-ok:     var(--color-green);
--lubi-surface-1: var(--background-primary);     /* 卡片 */
--lubi-surface-0: var(--background-secondary);   /* 画布 */
--lubi-line:      var(--background-modifier-border);
--lubi-line-soft: color-mix(in srgb, var(--lubi-line) 50%, transparent);

/* 字阶（1.2 比例，跟随 Obsidian 基准字号） */
--lubi-fs-xs: 11px; --lubi-fs-sm: 12px; --lubi-fs-md: 13px;
--lubi-fs-lg: 15px; --lubi-fs-xl: 20px; --lubi-fs-kpi: 28px;

/* 尺寸与层级 */
--lubi-h-sm: 28px; --lubi-h-md: 32px; --lubi-h-lg: 36px;
--lubi-radius-card: 12px; --lubi-radius-ctl: 8px; --lubi-radius-pill: 999px;
--lubi-shadow-1: 0 1px 2px rgb(0 0 0 / .06);
--lubi-shadow-2: 0 4px 16px rgb(0 0 0 / .08);
--lubi-ease: cubic-bezier(.2, .8, .2, 1); --lubi-dur: 140ms;
```

### 3.2 分类色三级派生（解决"块太淡、边太细"）

每个分类只配一个主色 `--c`，其余自动派生：

```css
.lubi-cat { --c-bg: color-mix(in srgb, var(--c) 14%, var(--lubi-surface-1));
            --c-bd: color-mix(in srgb, var(--c) 45%, transparent);
            --c-fg: color-mix(in srgb, var(--c) 70%, var(--text-normal)); }
.theme-dark .lubi-cat { --c-bg: color-mix(in srgb, var(--c) 22%, var(--lubi-surface-1)); }
```

### 3.3 默认分类色板（避开 accent 紫，色盲友好）

| 分类 | 现色 | 新色 | 说明 |
|---|---|---|---|
| 学习 | 蓝 | `#2F6FEB` 蓝 | 保持 |
| 运动 | 绿 | `#1F9D55` 绿 | 保持，提亮对比 |
| 睡眠 | 紫（撞 accent） | `#64748B` 石板灰蓝 + 斜纹 | "背景时间"降权 |
| 饮食 | 橙 | `#E8833A` 橙 | 保持 |
| 日常 | 灰 | `#A78B6D` 暖棕 | 与睡眠灰拉开 |
| 财务 | 黄 | `#D4A017` 金 | 保持 |

运行时兜底：若用户分类色与 `--interactive-accent` 色相差 < 20°，设置页给出提示"与主题强调色接近，建议更换"。

## 4. 分页面执行方案

### 4.1 全局顶栏（`src/ui/view.ts` + `styles.css`）

- 固定三段式：`grid-template-columns: 1fr auto 1fr`。左 = 日期/周期导航（回顾页显示"9/21–9/27"，任务页显示"本周"，**永不留空**）；中 = 记录·回顾·任务 分段控件（位置恒定）；右 = `＋ 记一条` + 更多菜单。
- 日期文字改为 `--text-normal` 加粗，"今天"态用小圆点徽标，不再整段紫色。
- 右侧两个裸图标（打开日记 / 设置）收进 `⋯` 菜单，降低视觉噪音；tooltip 带快捷键。
- 窄面板（< 720px）：中段分段控件变图标-only，左段只留 `‹ 9/26 ›`。

### 4.2 记录页（`src/ui/today.ts`）

**时间轴**
1. 首次渲染滚动到 `max(首条记录, 现在 - 2h)`；顶部/底部吸顶浮标"↑ 更早 2 条 · 00:00–07:30"，点击平滑滚动。修掉 `06:00` 刻度被裁切。
2. 布局改 `grid-template-columns: var(--lubi-gutter) minmax(0, 1fr) auto`，块宽弹性，财务栏紧贴，消除 130px 死区；`--lubi-tl-max` 改为 960px。
3. 块内排版：`标题 · 30min` 同一行左对齐，时间区间放第二行（≥ 45min 才显示）；< 20min 的块只显示标题，hover 出完整信息。
4. 块样式：背景 `--c-bg`，左边 4px `--c`，标题 `--c-fg`；睡眠块用 `repeating-linear-gradient` 斜纹 + 60% 透明度。
5. 时间黑洞可视化：空白 ≥ 30min 的区间 hover 时显示虚线框 +"记这段 42min"，点击直接打开预填模态（借鉴 Timing / Toggl）。
6. 并行记录提示从页面顶部横幅改为：重叠区域在时间轴上加细斜线标记 + 块角标 `⧉`，横幅折叠为顶部统计行里的一个可点徽标"并行 30min"。
7. 时间轴高度 `flex: 1` 占满视口，去掉底部 80px 留白。

**右侧栏**
- 环形图中心："14h 已记录"主数字 + "空白 10h"次数字（字号 ≥ 11px，现 9px 不达标）。
- 分类图例加迷你横条，与回顾页"按分类"同一组件（组件复用 `components.ts`）。
- 今日待办每项加 `▶ 开始` 按钮：点击以当前时间为开始打开记一条，关联该任务。
- 新增晚间（≥ 21:00）"今日收尾"卡片：覆盖率、最大黑洞、明日首个任务（借鉴 Sunsama shutdown ritual），可在设置关闭。

### 4.3 回顾页（`src/ui/review.ts`）

1. KPI 分层：左侧大卡"记录总时长 173.2h ↑12% vs 上周"（`--lubi-fs-kpi`），右侧 2×2 小卡（有效天数、日均、覆盖率、支出）。"日均 —"改为显示"12h（剔除 1 个异常日）"并提供切换。
2. 异常横幅 → 柱顶 `⚠` 徽标 + 顶部单行可收起提示；点击徽标直接跳到那天记录页并高亮问题记录。
3. 堆叠柱：堆叠顺序与图例顺序一致（自下而上 = 图例自左而右）；睡眠放最底层并用斜纹；柱宽 `clamp(16px, 60%, 48px)`；hover 整列高亮 + tooltip。
4. 年视图改为 GitHub 式热力格（365 格，颜色 = 覆盖率），月视图保留柱状。
5. 底部三卡等高对齐；"事项 Top 10"加横条，与"按分类"视觉统一；支出卡为空态时显示引导文案而非大片留白。

### 4.4 任务页（`src/ui/tasks.ts`）

1. 周日程区 `flex: 1` 占满剩余高度，内部滚动，修复 19:00 以后被截断；首屏自动滚到 `现在 - 1h`。
2. 表头加每日负载条：`计划 3.5h / 可用 10h`，超 90% 变橙、超 100% 变红（借鉴 Sunsama 超载警告）。
3. "项目"区从底部折叠条改为可展开抽屉（默认展开 1 行甘特），或移入左栏第三张卡，释放纵向空间。
4. 左栏"今天"与记录页"今日待办"使用同一组件，行为一致（勾选、开始、拖拽）。
5. 全天行任务名最小 12px，已完成的删除线改为降低不透明度 + ✓，避免"学习极限"难以辨认。
6. 拖拽反馈：拖动中显示幽灵块 + 目标时段高亮 + 时间气泡（与记录页拖拽统一视觉）。

### 4.5 记一条模态（`src/ui/modals.ts`）

1. 顶部「时间 | 支出」分段切换，财务从分类网格移出；两种模式各自表单，切换不丢已填内容。
2. 分类改单行胶囊（溢出横向滚动），标注数字 `1–6`，按数字键直接切换；选中态用 `--c-bg` + `--c-bd` 边框。
3. "做了什么"自动聚焦；支持一行自然语言：`9:00-10:30 学习 三明治定理` / `30min 跑步`，解析结果以灰色预览显示在输入框下方（借鉴 Amie）。输入时下拉最近 5 条同名事项。
4. 开始—时长—结束联动条保留；快捷时长与"从 xx:xx 接着记"合并为一行 chip，"接着记"取**开始时间之前最近一条记录的结束时间**（预览中出现当前 14:04 却建议"从 19:32 接着记"，需核对逻辑）。
5. 顶部色条改 4px 且随分类实时过渡（`transition: background var(--lubi-dur)`）。
6. 次要字段"关联待办 / 备注"保持折叠；底部 `取消`（Esc）/`记下 ⏎` 保留 kbd 提示。

### 4.6 编辑任务模态

1. 原生 `select` / `input[type=date]` 包一层统一外观（高度 `--lubi-h-md`、圆角 `--lubi-radius-ctl`、同款图标）。
2. "预计 150 min"显示为 `2.5h`，输入支持 `2.5h` / `150m`。
3. 状态分段控件保留，删除"当前状态：待办；修改后请点击保存"说明，改为有修改时标题旁出现"● 未保存"。
4. "受阻"改为开关（toggle），选中后展开"被什么阻塞"输入。

## 5. 交互、动效与可访问性

- **动效**：所有状态过渡 140ms `--lubi-ease`；拖拽松手块回弹 180ms；`prefers-reduced-motion` 下全部关闭。
- **焦点**：统一 `:focus-visible { outline: 2px solid var(--lubi-accent); outline-offset: 2px }`，时间轴块可 Tab 进入。
- **对比度**：正文 ≥ 4.5:1，块内标题在 `--c-bg` 上 ≥ 4.5:1（明暗主题各测一次）；最小字号 11px。
- **触控**：可点目标 ≥ 32×32（图标按钮现为 24/30px，窄面板统一到 32px）。
- **ARIA**：时间轴 `role="list"`、块 `aria-label="学习 三明治定理习题 08:30–11:00 2.5 小时"`；负载条 `role="meter"`。
- **快捷键总表**：`N` 记一条、`1/2/3` 切页、`T` 今天、`←/→` 前后一天，界面 `?` 弹出速查卡。

## 7. 验收标准

| 维度 | 标准 | 验证方式 |
|---|---|---|
| 布局稳定 | 三页切换时分段控件 x 坐标差 = 0 | `test/tasks-ui-layout.mjs` 新增断言 |
| 无裁切 | 时间轴首个刻度完全可见；周日程最后一个任务块完整可见 | 布局回归 + 截图 |
| 撞色 | 默认主题下任何分类色与 accent 色相差 ≥ 30° | `test/core.mjs` 色相计算单测 |
| 效率 | 键盘完成"记一条"≤ 4 次按键（`N` → 输入 → `⏎`） | 手测 + 冒烟 |
| 可读性 | 最小字号 ≥ 11px；正文对比度 ≥ 4.5:1（明/暗） | 截图 + axe 检查 |
| 窄栏 | 720px 宽下三页无横向滚动、无文字溢出 | 720px 截图 |
| 回归 | `npm test` 全绿；`LUBI_REQUIRE_BROWSER=1` 布局用例通过 | CI 本地 |

发布：每个 Sprint 结束 `npm run build` → 复制到 `.obsidian/plugins/lubi/` → 真实 Obsidian 明暗主题各验一遍，版本号依次 v1.4.0-alpha.1 / .2 / v1.4.0，并更新 `docs/mcp-lubi-plugin.md` 版本表。
